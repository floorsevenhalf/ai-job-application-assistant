# 兼容性评估

> 由 `pnpm evaluate` 生成。当前数据是规模有限、合成且经过脱敏的兼容性样本，不代表所有招聘网站。Confidence 是规则评分，不是真实概率。本页指标仅来自确定性的 Rule Matcher。Scripted Fake Provider 的 Hybrid 结果单独报告，不代表真实大模型性能。

## 1. 评估数据集

- 38 个字段案例，来自 8 个最小化 HTML fixture
- 类别：校园招聘、ATS、企业招聘页和通用表单
- 不包含复制的网站品牌、账号数据、真实 Profile 值或生产页面 HTML

## 9. 已知限制

Fixture 是小型重构结构，不是代表性样本。它们不覆盖 Shadow DOM、iframe、复杂异步组件、多语言变体和真实框架时序差异。Autofill 成功率仅描述 fixture 支持的原生控件。

Section Context 对比：不使用和使用时召回率均为 69.7%；错误匹配率由 2.6% 降至 0.0%。Scanner 只提取最近的明确 Section/Group 标题。

## 10. 对 AI Matcher 的启示

Fallback 数据集包含 7 个预期可识别但结果为 ambiguous 或 unmatched 的字段。数据已脱敏，只包含 Descriptor、候选路径和预期路径，不包含 Profile 值。语义回退必须维持规则优先、高精确率和人工审核边界。`reports/ai/hybrid_evaluation.json` 使用 Scripted Fake Provider，仅用于验证管线行为，不是真实模型 Benchmark。
