# Compatibility Evaluation

> Generated by `pnpm evaluate`. This is a finite, synthetic, sanitized compatibility sample and does not represent all recruiting websites. Confidence is a rule score, not a probability. These metrics are produced by the deterministic Rule Matcher only. Scripted Fake Provider Hybrid results are reported separately and do not represent real LLM performance.

## 9. Known Limitations

The fixtures are small reconstructed structures, not a representative sample. They exclude Shadow DOM and iframe execution, complex asynchronous widgets, localization variants, and real framework timing diversity. Autofill success values describe fixture-supported native controls only.

Section context comparison: recall 69.7% without versus 69.7% with section context; wrong-match rate 2.6% versus 0.0%. The scanner only takes the nearest explicit section/group heading.

## 10. Implications for AI Matcher

The fallback dataset contains 7 expected fields that are ambiguous or unmatched. It is sanitized and contains descriptors, candidates, and expected paths but no profile values. Semantic fallback work must preserve the rule-first, high-precision, human-review boundary. The separate reports/ai/hybrid_evaluation.json uses a Scripted Fake Provider only to validate pipeline behavior; it is not a real-model benchmark.
